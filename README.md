# To-Do Web Application Frontend

A simple and modern To-Do application built with React, containerized for easy deployment and local development using Docker.

#Getting Started with Docker

Follow these steps to pull and run the TODO-frontend application from Docker Hub.

#Pull the Docker Image
Use the following command to pull the latest development image:

docker pull vinoge/todo-frontend:dev

#Use following command to run the application
docker run -p 5173:5173 vinoge/todo-frontend:dev
